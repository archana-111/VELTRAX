VELTRAX

Logistics and transportation template for Next.js. It builds to a folder of static files.

1. Introduction

VELTRAX is a multipage marketing site for a freight, transport, warehousing, and supply chain company. The company in the copy is fictional. Figures, testimonials, staff, and shipments are labeled as demonstration content.

Three homepages ship with the template: global logistics at /, freight at /home-freight/, and warehousing at /home-warehousing/.

A live preview URL is not included. Deploy the out folder, then add the resulting address to your marketplace listing.

2. Requirements

  • Node.js 20.9 or newer. This project was built with Node 20.15.
  • npm 10 or newer.
  • A network connection the first time you build, so next/font can download Schibsted Grotesk and Source Sans 3.

You do not need a database, an API key, or a Node server in production.

3. Installation

npm install
copy .env.example .env.local

On macOS or Linux, use cp .env.example .env.local. Set NEXT_PUBLIC_SITE_URL to the public address of the site, with no trailing slash. That value is written into canonical links, Open Graph URLs, sitemap.xml, and robots.txt at build time.

4. Local development

npm run dev

The dev server prints a local URL, usually http://localhost:3000. Edits to React components and data files refresh in the browser. The quote form and tracker behave the same way they will after export: nothing is sent to a server.

5. Production build

npm run build

The command typechecks the project and writes a static site. It does not start a server. npm start is not the hosting command for this template, because output: "export" does not produce a Node server bundle.

Optional checks before you pack a release:

npm run lint
npm run typecheck

6. Static export

next.config.ts sets output: "export", trailingSlash: true, and images.unoptimized: true. The default image optimizer needs a server, so it is turned off. Dynamic routes set dynamicParams = false and generateStaticParams, which is required for export.

After a successful build, out/ contains one index.html per route, plus 404.html, sitemap.xml, robots.txt, images, and JavaScript.

Do not add Server Actions, middleware, cookies, or a route handler that reads the request. Those features are incompatible with this export.

7. Deployment

Upload the contents of out/ to any static host: Netlify, Cloudflare Pages, Amazon S3, GitHub Pages, or a classic Apache or nginx directory. The home page is index.html. Inner pages are folders with their own index.html because trailing slashes are enabled.

Rebuild after you change NEXT_PUBLIC_SITE_URL. The URL is fixed at build time.

No preview URL is supplied with the download. Put your deployed address in the marketplace listing yourself. Approval is not guaranteed by this documentation.

9. Homepage customization

Home 01 is src/components/sections/HomeGlobal.tsx, mounted by src/app/page.tsx. Home 02 is HomeFreight.tsx and FreightHero.tsx. Home 03 is HomeWarehouse.tsx. The footer lists all three so a reviewer can find them.

Shared facts, including the sample metrics and the five-step sequence, live in src/data/company.ts. Change those before you rewrite the JSX. To make a different homepage the root URL, move the component into src/app/page.tsx and point the old one at another route.

10. Theme color customization

Colors are CSS variables at the top of src/styles/theme.css.

  • --navy #101D29, structure and primary buttons
  • --paper #F5F4EF, page background
  • --signal #F46B38, rules and the orange button fill
  • --signal-ink a darker orange for small text, so contrast stays readable
  • --ink and --muted for body and secondary text
  • --line for hairline dividers

Change the variables. Do not hunt for hex values in components. Orange text uses --signal-ink because the brighter brand orange fails normal-text contrast on the paper background.

11. Typography customization

Fonts are loaded in src/app/layout.tsx with next/font/google. Schibsted Grotesk is the display face. Source Sans 3 is the body face. Both are SIL Open Font License and are self-hosted in the export.

To switch fonts, replace the two next/font calls and keep the CSS variables --font-display-family and --font-body-family. Headline sizes are in theme.css under .hero-a h1, .section-head h2, and .page-hero h1.

12. Navigation customization

src/data/navigation.ts builds the header, the services menu, and the footer from the service list plus the company links. Add a page by creating a route under src/app and adding its label and href here. The services mega menu updates when you add a service in services.ts.

The mobile drawer reads the same data. Keep link text short enough for a 320px screen.

13. Service and project editing

Services: src/data/services.ts. The slug becomes the URL /services/[slug]/. Each service needs a name, summary, narrative, capabilities, and an image from src/data/images.ts.

Industries: src/data/industries.ts. Point serviceSlugs and projectSlug at existing entries.

Projects: src/data/projects.ts. The listing page filters by the text before · in sector.

After adding or removing a slug, run npm run build so the static page is generated. Unknown slugs are not rendered on demand.

14. Blog editing

Articles live in src/data/articles.ts. A category string is enough to appear in the filter. The listing shows four articles per page and paginates in the browser. Related articles on a detail page prefer the same category.

Write real dates as readable strings, the way the sample articles do. Do not use placeholder Latin.

15. Tracking demo customization

Sample shipments are in src/data/shipments.ts. The page accepts IDs shaped like VLX-00000-ABC. These three resolve:

  • VLX-24081-HAM ocean, on the water
  • VLX-24092-SIN air, held for a document
  • VLX-24105-ORD road, out for delivery

Any other well-formed ID shows the not-found state. The component is src/components/forms/TrackPanel.tsx.

To connect a provider, replace findShipment with a call that returns the same Shipment shape: id, status, progress from 0 to 100, origin, destination, and milestones marked complete, current, or upcoming. A static export cannot hide an API key or call a provider during the request. Use a client-side call to your own public endpoint, or regenerate the dataset at build time from a file you control. Do not ship a secret in the browser bundle.

16. Quote form integration

src/components/forms/QuoteForm.tsx checks name, email, phone, company, freight type, origin, destination, weight, optional dimensions, and message. On success it states that nothing was sent. The contact form in ContactForm.tsx works the same way.

For production, post the values from the submit handler to a service you operate:

  • A form endpoint such as Formspree, Getform, or your own serverless function on a different host
  • An email API called from that endpoint, not from this static site with a secret key
  • A CRM create-lead request, again from a server you control

Keep the validation. Remove the sentence that says the message stayed in the browser once a real delivery exists. The contact page can pass ?topic=Careers from the sample job listings.

17. SEO customization

Each page calls createPageMetadata in src/lib/seo.ts with a title, description, path, and optional image. The root layout adds the title template %s — VELTRAX, Open Graph defaults, and an Organization JSON-LD block. Service pages add Service schema. The FAQ page adds FAQPage schema. Articles add Article schema.

src/app/sitemap.ts and src/app/robots.ts emit sitemap.xml and robots.txt during the export. Change the public URL in the environment, not inside those files.

18. Asset licensing

Read ASSET_LICENSES.md before you package a sale. The photographs were generated for this template. They are not stock photos, and they are not images from the design references. If your marketplace account restricts synthetic images, replace the files in public/images and the alt text in src/data/images.ts.

Fonts are SIL Open Font License. Lucide icons are ISC. No third-party customer logos are included.

19. Troubleshooting

SymptomWhat to do
Build asks for Google fonts and fails offlineBuild once online, or vendor the font files and switch next/font/google to next/font/local.
npm start refuses to runExpected. Serve the out folder with your host or any static server.
A new slug 404sRun npm run build again. Export does not create routes at request time.
Canonical URL is example.comSet NEXT_PUBLIC_SITE_URL and rebuild.
Images look softThe export disables the Next image optimizer. Compress replacements yourself before adding them.
Menu or motion feels wrongThe site respects prefers-reduced-motion. Check the operating system setting.
